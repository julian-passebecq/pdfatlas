# PDF Atlas

Public PDF source repository used by AtlasNote.

## Library structure

- `library/data-engineering/apache-spark/apache-spark-30-concepts.pdf`
- `library/data-engineering/apache-spark/pyspark-pandas-dataframe-guide.pdf`
- `library.json` contains stable IDs, metadata, categories, page counts and SHA-256 checksums.

The PDF files are byte-identical to the original uploaded files. AtlasNote should reference a commit-pinned `raw.githubusercontent.com` URL rather than a mutable branch URL.

Rights are recorded as reference-only because redistribution licences were not established from the supplied documents.
